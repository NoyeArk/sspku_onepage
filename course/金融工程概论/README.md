# 金融工程概论

## 1. 课程介绍

点名之前会提前在群里通知，除了点名之外只有考试，没有小组作业之类的任务。

最后一节课老师会说考哪些题目，一般是计算题 + 开放题。

## 2. 考试原题

### 2.1 2025年9月秋季学期

计算题：

1. 远期合约的计算 $f$
2. 第一问计算的 $f$ 是否满足BSM方程：带入验证即可
3. BSM方程如何推导
4. 伊藤引理如何推导
5. 伊藤引理中的dz如果变成dz1、dz2如何计算
6. 设计一个货币互换

开放题：

1. 美国国债规模突破 38 万亿美元对国际金融衍生品市场的影响
2. 日本央行加息至0.75%对国际金融衍生品市场的影响
