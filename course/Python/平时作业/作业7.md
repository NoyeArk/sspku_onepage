## 1. 变量设置与数据处理


```python
import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
from sklearn.preprocessing import StandardScaler
from sklearn.model_selection import train_test_split
from sklearn.neural_network import MLPClassifier
from mlxtend.plotting import plot_decision_regions
from sklearn.metrics import confusion_matrix
from sklearn.metrics import classification_report
from sklearn.metrics import cohen_kappa_score
```


```python
data=pd.read_csv('../data/数据6.1.csv')
X = data.iloc[:, 1:]
y = data.iloc[:, 0]
X_train, X_test, y_train, y_test = train_test_split(X,y,test_size=0.3, random_state=10)
```

读取数据文件，将第一列（V1，收入档次）作为响应变量y，其余列（V2、V3、V4）作为特征变量X。使用`train_test_split`函数将数据集按7:3的比例划分为训练集和测试集，其中测试集占30%，`random_state=10`确保结果可重复。


```python
scaler = StandardScaler()
scaler.fit(X_train)
X_train_s = scaler.transform(X_train)
X_test_s = scaler.transform(X_test)
X_train_s = pd.DataFrame(X_train_s, columns=X_train.columns)
X_test_s = pd.DataFrame(X_test_s, columns=X_test.columns)
```

使用`StandardScaler`对特征变量进行标准化处理。标准化过程：首先在训练集上拟合标准化器（计算均值和标准差），然后对训练集和测试集进行标准化转换，将特征缩放到均值为0、标准差为1的分布。有助于神经网络模型更好地收敛，因为不同特征的量纲和数值范围被统一了。

---

## 2. 单隐藏层多分类问题神经网络算法

### 2.1 训练模型


```python
model = MLPClassifier(solver='sgd',learning_rate_init=0.01,learning_rate='constant',tol=0.0001,activation='relu',hidden_layer_sizes=(3,),random_state=10,max_iter=2000)
model.fit(X_train_s, y_train)
model.score(X_test_s, y_test)
```




    0.9260450160771704

单隐藏层神经网络的测试集准确率为92.60%，表明模型表现良好。该模型使用随机梯度下降（SGD）优化器，学习率为0.01，激活函数为ReLU，隐藏层包含3个神经元。

## 3. 双隐藏层多分类问题神经网络算法

### 3.1 训练模型


```python
model = MLPClassifier(
    solver='sgd',
    learning_rate_init=0.01,
    learning_rate='constant',
    tol=0.0001,
    activation='relu',
    hidden_layer_sizes=(3,2),
    random_state=10,
    max_iter=2000
)
model.fit(X_train_s, y_train)
model.score(X_test_s, y_test)
```




    0.7684887459807074

双隐藏层神经网络的测试集准确率为76.85%，相比单隐藏层模型的92.60%有所下降。该模型包含两个隐藏层，第一层有3个神经元，第二层有2个神经元。准确率下降可能的原因包括：模型结构更复杂导致过拟合、需要更多的训练迭代或不同的超参数设置。在实际应用中，并非隐藏层越多性能越好。

```python
cohen_kappa_score(y_test, pred)
```




    0.6160362152337187

Cohen's Kappa系数为0.616，这是一个衡量分类器一致性的指标。Kappa值的解释：
- 0.00-0.20：几乎没有一致性（poor）
- 0.21-0.40：轻微一致性（fair）
- 0.41-0.60：中等一致性（moderate）
- 0.61-0.80：高度一致性（substantial）
- 0.81-1.00：几乎完全一致（almost perfect）

当前值为0.616，属于"高度一致性"，表明模型预测与真实结果之间有较好的一致性，但仍有改进空间。相比简单的准确率，Kappa系数考虑了随机一致性，能更准确地评估模型性能。

## 5. 运用两个特征变量绘制多分类神经网络算法决策边界图


```python
X2_train_s = X_train_s.iloc[:, [1, 3]]
X2_test_s = X_test_s.iloc[:, [1, 3]]
model=MLPClassifier(solver='sgd',learning_rate_init=0.01,learning_rate='constant',tol=0.0001,activation='relu',hidden_layer_sizes=(3,2),random_state=10,max_iter=2000)
model.fit(X2_train_s, y_train)
model.score(X2_test_s, y_test)
```




    0.8135048231511254

使用两个特征变量（V2工作年限和V4违规操作积分）训练的双隐藏层神经网络模型，在测试集上的准确率为81.35%。相比使用全部三个特征变量的模型（准确率76.85%），准确率有所提升。这可能是因为：
1. 特征维度的降低减少了过拟合风险
2. 选用的两个特征（V2和V4）对收入档次具有更强的判别能力
3. 模型在较少的特征空间内更容易学习到有效的分类边界



