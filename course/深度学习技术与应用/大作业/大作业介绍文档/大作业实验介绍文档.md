## 一、作业背景

大语言模型（LLM）有多种使用方式，它们在成本、效果和适用场景上各有取舍：

- **Prompting**：零训练成本，通过提示词设计驱动模型回答
- **SFT（监督微调）**：在任务数据上微调模型参数，让模型学习任务格式与模式
- **RAG（检索增强生成）**：引入外部知识库，让模型先检索再生成
- **Agent（智能体）**：赋予模型自主规划和多步推理能力，通过工具调用完成复杂任务

本次大作业要求同学们在**同一个模型（openPangu-7B）、同一个数据集（HotpotQA）** 上，依次实现上述四种方法，通过**统一的评估指标（EM / F1）** 对比它们的效果差异，深入理解每种方法的适用场景与局限性。

## 二、数据集介绍

### 2.1 HotpotQA 概述

[HotpotQA](https://arxiv.org/pdf/1809.09600)是一个经典的英文**多跳问答**基准数据集。与简单的单轮问答不同，HotpotQA 中的问题需要结合多篇 Wikipedia 文章的信息才能正确作答，例如先从文章 A 中找到一条线索，再到文章 B 中找到答案。

**核心统计：**

| 属性 | 值 |
|------|---|
| 原始训练集 | 90,564 条 |
| 原始验证集（distractor 版本） | 7,405 条 |
| 答案形式 | 短实体名 / yes / no |
| 推理类型 | bridge（桥接推理）、comparison（比较推理） |
| 每条附带上下文 | 10 篇 Wikipedia 段落|

**数据示例：**

```json
{
  "question": "Were Scott Derrickson and Ed Wood of the same nationality?",
  "answer": "yes",
  "type": "comparison",
  "level": "hard",
  "supporting_facts": [["Scott Derrickson", 0], ["Ed Wood", 0]],
  "context": [
    ["Scott Derrickson", ["Scott Derrickson (born July 16, 1966) is an American director..."]],
    ["Ed Wood", ["Edward Davis Wood Jr. was an American filmmaker..."]]
  ]
}
```


### 2.2 数据集的两种设置

HotpotQA 提供两种实验设置：

| 设置 | 说明 |
|------|------|
| **Distractor** | 每条数据自带 10 篇 Wikipedia 段落（2 gold + 8 干扰），模型从这 10 篇中推理作答 |
| **Fullwiki** | 每条数据带实际检索Wikipedia 的段落（不一定有gold），模型需从 HotpotQA 官方提供的 Wikipedia 语料库中自行检索相关信息再推理作答 |

**本次大作业采用 Fullwiki 设置**，但是推理时**不允许**使用数据集中自带的 10 篇参考文档（`context` 字段）和关键句子（`supporting_facts` 字段），模型需要依靠自身知识，或从 Wikipedia 语料库 / 互联网中检索信息来回答问题。这一设置更贴近真实应用场景，也更能体现 RAG 和 Agent 方法的价值。

由于完整数据集处理时间较长，我们已从原始数据集中划分出子集供本次大作业使用。**请务必使用我们提供的数据子集**，不要使用原始完整数据集。

> 数据集获取见**实验指导文档**。

### 2.3 评估指标

全部四个 Part 使用统一的评估指标：

| 指标 | 说明 |
|------|------|
| **EM（Exact Match）** | 标准化后的预测答案与标准答案是否完全一致，一致则为 1，否则为 0 |
| **F1 Score** | 基于 token 级别的精确率和召回率的调和均值 |

> 指标计算的代码见**实验指导文档**，必须使用此指标计算。
